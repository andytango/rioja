# Content and style guidelines

## Language
- Use British English spelling throughout (-ise, -our, -re endings)
- Write clearly and directly

## Typography
- Use sentence case for all headings and titles
- Exceptions: proper nouns, acronyms, brand names
- Berkeley Mono for headings and code
- Noto Sans for body text

## Punctuation
**Never use em dashes (—).** Instead:
- Use colons (:) for elaboration
- Use semicolons (;) for related clauses
- Use parentheses ( ) for asides
- Use commas (,) for light parenthetical phrases

## Standards
- Optimise images (WebP preferred)
- Semantic HTML with proper heading hierarchy
- Adequate colour contrast for accessibility
